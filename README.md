# 🖼️ Responsive Image Gallery

A modern and responsive image gallery built using **HTML, CSS, and JavaScript**.

The project features smooth horizontal scrolling, navigation buttons, mouse-wheel scrolling, custom scrollbar styling, hover effects, and responsive design for different screen sizes.

## ✨ Features

* 📱 Fully responsive design
* 🖼️ Horizontal image gallery
* ⬅️ Previous button
* ➡️ Next button
* 🖱️ Mouse-wheel horizontal scrolling
* 🎨 Custom gradient scrollbar
* ✨ Image hover effects
* 🔄 Smooth scrolling
* 📐 Works across different screen sizes

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**

While building this project, I practiced:

* DOM selection and manipulation
* `addEventListener()`

* Smooth scrolling
* CSS responsive design
